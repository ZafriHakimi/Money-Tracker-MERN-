## Money Tracker (MERN Stack)

Money Tracker is a simple full-stack web application built with the MERN stack that helps users record and track daily income and expenses. Users can add transactions with details such as name, amount, description, and date, and view them in a structured list with real-time balance calculation based on all recorded transactions.

This project uses MongoDB for data storage, Express.js and Node.js for building RESTful APIs on the backend, and React.js for the frontend interface. It focuses on core full-stack fundamentals such as API design, database integration, state management, and date/time handling, while keeping the codebase simple and easy to extend with additional features like dashboard, charts & many more in the future.

This application was built primarily as a learning project to explore full-stack web development using the MERN stack, and it represents my first successfully completed end-to-end full-stack application, covering both frontend and backend development.
